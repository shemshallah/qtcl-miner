# qtcl-miner
QTCL Miner client 
[x]mining
[x]transactions
[x]wallet management
[in progress]p2p

All oracles will maintain a 3 qubit w tripartite state and measure independently synthesizing a network average or mean over time but initially focusing on snapshots fed from the server at http://qtcl-blockchain.koyeb.app 
The qtcl_client_mar30_stable is PRE p2p if we want to build p2p a different way than its being implemented in qtcl_client.py the main Client. 

git clone https://github.com/shemshallah/qtcl-miner/
pip install -r requirements
python3 qtcl_client.py

Also in progress is an android port.
